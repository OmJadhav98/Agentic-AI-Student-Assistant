# Agentic AI-Powered Personalized Student Assistant

An AI-powered academic assistant designed to provide personalized support to students based on their study materials, previous-year question papers, quizzes, and performance.

## Current Implementation

The current prototype includes:

- FastAPI backend
- PostgreSQL database
- Student onboarding
- PDF upload and text extraction
- Text chunking
- Sentence embeddings
- FAISS-based semantic retrieval
- PYQ analysis
- Basic quiz generation
- Performance tracking
- Weak-topic detection

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- PyMuPDF
- Sentence Transformers
- FAISS
